# SEO Helper Skill

## What I do
1. **Keyword research** — find relevant keywords and related search phrases for a topic.
2. **Meta tags** — write an SEO title (under 60 characters) and meta description (under 160 characters).
3. **Content check** — review text for heading structure, readability, and keyword usage.
4. **Content brief** — create an outline with headings (H1, H2, H3) and FAQ suggestions.

## How I work
- Always ask which website/page and which country/language the SEO is for.
- Use web search to check what currently ranks for the target keyword.
- Give results in a simple table: keyword, intent, difficulty, recommendation.
- Write meta tags ready to copy-paste.
